## Next: v12 — 4D GLS Kangaroo

**Goal:** Reduce puzzle #135 from ~2,000 years to **seconds** on a single GPU.

**Mathematical basis:**
```
Over F_{p²}: End(secp256k1) has rank 4, generated by {id, φ, π, φ∘π}
4D GLV decomposition: k = k₁ + k₂λ + k₃p + k₄λp  (mod n)
Each kᵢ ≈ 33 bits  →  ops ≈ C × 2^33.75  ≈  1.4 × 10^10
At 1 Gop/s: ~14 seconds
```

### v12 Milestones

#### Phase 1 — F_{p²} Foundation
- [ ] **Fp2 arithmetic (CPU):** `Fp2 { a: Fe, b: Fe }` struct, add/sub/mul/inv over F_{p²}
- [ ] **Frobenius:** `pi(x,y) = (x^p, y^p)` on F_{p²} points (= complex conjugate for p≡3 mod 4)
- [ ] **Point operations on E/F_{p²}:** add, double, scalar_mul over F_{p²}
- [ ] **Verify:** π(P) + φ(π(P)) forms independent 4D structure

#### Phase 2 — 4D Decomposition
- [ ] **4D LLL lattice reduction:** decompose k ∈ [0,2^135) into (k₁,k₂,k₃,k₄), each ≈ 33 bits
- [ ] **Basis construction:** build 4×4 LLL basis from {n, λ, p, ...}
- [ ] **Verify:** k ≡ k₁ + k₂λ + k₃·(scalar for π) + k₄·(scalar for φπ) mod n

#### Phase 3 — 4D Kangaroo
- [ ] **Jump axes:** {G, φG, πG, φπG} — 4 axes instead of 3
- [ ] **Jump table:** 29-band × 4 axes = extended table
- [ ] **DP canonical form:** for 4D walk, define canonical representative under 4D automorphisms
- [ ] **Collision recovery:** from 4D DP match, recover k via CRT over the 4 components
- [ ] **CPU prototype:** verify correctness on small (48-bit) instances

#### Phase 4 — CUDA 4D Kernel
- [ ] **F_{p²} arithmetic in CUDA:** efficient device-side Fp2 struct
- [ ] **4D persistent kernel:** adapt v11 kernel for 4-axis walk
- [ ] **Shared memory layout:** 4 axes × 29 bands × 96 bytes — verify fits L1
- [ ] **Warp-ballot 4D DPs:** extend coalescing to 4D canonical key
- [ ] **Benchmark:** measure actual C for 4D walk, compare to 2D

#### Phase 5 — Integration & Launch
- [ ] **CLI flag:** `--gls4d` to activate 4D mode
- [ ] **Distributed 4D:** coordinator handles 4D DP table
- [ ] **Checkpoint 4D:** save/restore 4D animal state
- [ ] **Target:** run puzzle #135 end-to-end, verify solution

## Cloud GPU Launch Instructions (tonight)

### Recommended: RunPod / Vast.ai

```bash
# 1. Clone repo
git clone https://github.com/AFKmoney/sinGRAAL.git
cd sinGRAAL/kangaroo

# 2. Build with CUDA
cargo build --release --features cuda

# 3. Launch v11 (2D, current production)
./target/release/kangaroo \
  --target-x <puzzle-135-x> \
  --target-y <puzzle-135-y> \
  --range-bits 135 \
  --all-gpus \
  --checkpoint checkpoint.bin

# 4. Verify research modules
./target/release/kangaroo --research4d --range-bits 135
./target/release/kangaroo --benchmark-c --range-bits 48 --trials 200
```

### Puzzle #135 Target

The Bitcoin puzzle #135 target public key is publicly known. Use `--range-bits 135` with the correct `--target-x` and `--target-y`.

### Distributed Mode (multiple machines)

```bash
# Machine A (coordinator):
./kangaroo --serve --bind 0.0.0.0:5135 \
  --target-x <x> --target-y <y> --range-bits 135

# Machines B, C, ... (workers):
./kangaroo --coordinator A.ip:5135 --all-gpus --range-bits 135
```
